# soft evidence.
A free, animated whimsigoth mixtape and personal writing archive.

## Publish on GitHub Pages
1. Create a **public** GitHub repository, e.g. `soft-evidence`.
2. Upload the five files (`index.html`, `style.css`, `script.js`, `content.js`, `README.md`) to the **root** of the repository (not inside a folder).
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
4. Your website will appear at `https://YOUR-USERNAME.github.io/soft-evidence/` (usually after a few minutes).

## Personalize
- Edit `content.js` to add your real song titles, artist names, links, and memories, and write your essays.
- Edit the main title, subtitle, and about text in `index.html`.
- Edit the colors in the `:root` section at the top of `style.css`.

Songs open on YouTube/Spotify via links; the site does not host copyrighted music.

Note: GitHub Pages is public. Avoid putting private information about other people in your content.
